# 🎬 Movie Recommendation System

## 🚀 Overview
This project is a Machine Learning based Movie Recommendation System that suggests movies similar to the user's selected movie. It helps users discover new movies based on their interests.

## 🎯 Features
- Recommends similar movies instantly
- Content-based filtering approach
- User-friendly interface
- Fast recommendations using similarity scores
- Built with Python and Streamlit

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Pickle
- Streamlit

## 📊 How It Works
1. User selects a movie name
2. System finds similar movies
3. Similarity score is calculated
4. Top recommended movies are displayed

## 🤖 Machine Learning Technique
- Content-Based Recommendation
- Cosine Similarity
- Feature Engineering using movie metadata
